# Invoice logo

`mesk-vlab-logo.png` is a prepared image derived from the Mesk | vlab Ai logo supplied by the user for the invoice redesign. Prepared using the image editing tool. It is bundled locally so invoice rendering does not require an external logo host. A configured company logo takes precedence on actual invoices; the invoice demo explicitly uses this image.

`mesk-share.png` is the same supplied Mesk logo optimized through Next's image optimizer at 1200×400 (73,260 bytes), saved as a static public PNG for social crawlers. The developer's sales demo uses it independently of customer tenant logos.
