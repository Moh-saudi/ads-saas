# بيانات عرض العميل

البيانات في `demo.ts` و`operations-demo.ts` هي fixtures لمسارات `/demo` فقط؛ لا تنفذ إدخالًا إلى Supabase أو إنشاء حسابات دخول.

استكملت الأطراف بجهة مالكة وصاحب امتياز، وبيانات مستخدمين تجريبيين لأسماء الفريق، وتراخيص الأصول الـ18، وبنود عقود جميع الأصول المؤجرة الـ14. قيم العقود محسوبة من بنودها وفق أساس 30 يومًا، ومؤشرات الإيراد مبنية على أسعار الأصول نفسها. أضيفت مشتريات مستلمة، وأمر تركيب مكتمل، وحركات مخزون تفسّر كامل الأرصدة المعروضة، وطلب إعلان قيد المتابعة، وقسط حق استغلال، وفواتير متأخرة وللمورد، وسجل تصحيح موقع.

`npm run test:demo` ناجح: جميع مجموعات التشغيل الـ27 غير فارغة، وفحص المراجع والعلاقات والتواريخ وقيم العقود والحسابات المدينة والدائنة ومطابقة حركات المخزون وقيمته، وربط الموظفين والمستخدمين. نجح بناء الإنتاج مع TypeScript. فحص المتصفح موثق في `demo-data-browser.json`؛ ليس اختبارًا لمعاملات إنتاجية أو لخرائط OSM المستضافة.

## مراجعة الخرائط والتحصيلات

أعيد توزيع الإحداثيات التقريبية التجريبية بين التجمع والشروق، مع تنويه في ملاحظات كل أصل بأنها ليست مواقع معتمدة. طوبق تحصيل الشهر (18,000 ج.م) مع المدفوع على فواتير المعلنين، وصرف الرواتب الحالي (8,500) مع بند الراتب المسدد، وأضيف سداد الجهة المالكة PAY-001 (36,000). الحركات التاريخية أمثلة مستقلة للتدفقات النقدية؛ فواتير الشاشة ليست سجل كل الأشهر التاريخية.

نجح `npm run test:demo` والبناء النهائي. Chromium عند 1440 و390 تحقق من 18 صف أصل و18 علامة SVG بمسارات متميزة بعد استقرار حركة الخريطة، وفتح بطاقة MD-0101 بالنقر على العلامة، وظهور الشروق وطريق السويس، وتحصيل 18,000 ومتبقي معلنين 28,500 ومستحق دفع 8,000، ونصي حركتي التحصيل وسداد الجهة في دفتر الخزينة. نتائج `demo-map-collections-browser.json`.

القيود: عدد بلاطات OSM المحملة داخل متصفح الاختبار صفر، فلا يعد ذلك تحققًا من خلفية الخريطة. طلب HTTP منفصل إلى tile.openstreetmap.org أعاد 200. محاولة الوصول إلى نطاق Vercel من بيئة التنفيذ رُفضت عبر الشبكة (CONNECT 403)، فلم تؤكد هذه الجولة حالة النسخة المنشورة. لم تعدل قاعدة Supabase أو بيانات الشركة الفعلية.
