# مسميات الواجهة للسوق المصري

نستخدم لغة تجارية واضحة في القوائم والنماذج ورسائل الخطأ والدليل. لا تتغير أسماء الجداول أو مسارات الصفحات أو الحسابات المحاسبية بسبب هذه المسميات.

| المصطلح السابق | المسمى المعتمد | المقصود |
|---|---|---|
| العقود الصاعدة | عقود استغلال المواقع | اتفاق الشركة مع الجهة المالكة أو صاحبة الامتياز على المواقع والمدة والمقابل |
| الأصول والمواقع | اللوحات والمواقع | اللوحات الإعلانية ومقاساتها ومواقعها وحالتها |
| العملاء والأطراف | العملاء والموردون والجهات | المعلنون والموردون والجهات المالكة وأصحاب الامتياز |
| الفحص الميداني والوسوم | المتابعة الميدانية | زيارات الفحص وأكواد تعريف اللوحات |
| الصيانة وأوامر العمل | التركيب والصيانة | تكليفات الفنيين ومتابعة التنفيذ |
| الخزينة والمصروفات | الخزينة والبنوك | المقبوضات والمدفوعات والتحويلات والقيود |
| طلبات موقع الشركة | طلبات العملاء | طلبات الإعلان الواردة من الموقع |
| سجل المراجعة | سجل التعديلات | من عدّل البيانات ومتى؛ يختلف عن ميزان المراجعة المحاسبي |
| سلسلة التعاقد | توافق مدد العقود | مراجعة فترة حجز المعلن مقابل مدة استغلال الموقع |

الترخيص تصريح مرتبط باللوحة، وليس عقد استغلال الموقع ولا عقد المعلن. «صاحب الامتياز» قد يكون الوطنية أو شركة أخرى، فلا يُسمّى الحقل باسم شركة بعينها. تظل مصطلحات مثل القيود اليومية وميزان المراجعة والإهلاك والأصل المحاسبي كما هي في الحسابات. «نسبة اللوحات المحددة» تقيس اكتمال الإحداثيات، ولا تعني دقة الموقع الميدانية.

الفيديوهات المسجلة سابقًا تحتفظ بالمصطلحات التي ظهرت وقت تسجيلها؛ هذه الوثيقة والواجهة الحالية هما المرجع للمسميات الجديدة.
